Proyecto de Prácticas en Angular

Se logró migrar de PHP hacia Angular el proyecto web de las prácticas. Se clonaron la mayoría de las funciones de la versión actual para convertirlas en una aplicación de página moderna, reactiva y estructurada en componentes.

Usamos json-server para poder recrear el funcionamiento real del proyecto con una base de datos simulada. Si lo hacíamos solo de manera estática y local, no se podrían apreciar las operaciones CRUD reales que tiene el sistema (descuento de stock, registro de reservas, creación de cupones, etc.).
